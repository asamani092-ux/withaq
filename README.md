# وثاق — منصة مسارات حفظ القرآن الكريم

منصة عرض وطباعة للخطط التعليمية، على Cloudflare Workers + D1 + R2.

**مبدأ حاكم:** ملفات المسارات مصدر للقراءة فقط. شعار المستخدم كائن منفصل في R2 وموضعه سطر في D1، يُدمج لحظة العرض أو الطباعة في نسخته وحده. «استعادة الأصل» تعيد الملف كما اعتُمد.

## البنية
```
web/                 الواجهة (تُخدم كـ static assets من الـ Worker)
  index.html app.js assets/{pdf.js, شعار وثاق}
worker/src/index.ts  الـ API كاملًا
migrations/0001_init.sql
seed/                ملفات المسارات وصور المعاينة — خارج Git، تُرفع إلى R2
scripts/seed-r2.sh
```

## الإقلاع
```bash
npm install
npx wrangler login

npx wrangler d1 create withaq          # انسخ database_id إلى wrangler.toml
npx wrangler r2 bucket create withaq-files

npm run db:remote                      # تطبيق الترحيل على الإنتاج
npm run db:verify                      # تحقق فعلي أن الجداول أُنشئت
npm run seed:r2                        # رفع الـ PDF وصور المعاينة إلى R2
npm run deploy
```
ثم اربط النطاق `withaq.sam-dev.win` من لوحة Cloudflare أو بإلغاء التعليق عن `[[routes]]`.

> بوابة الترحيل: لا تعتمد على «تم الدمج». شغّل `npm run db:verify` وتأكد من ظهور الجداول قبل أي تجربة إطلاق. أي `no such column` في الإنتاج سببه ترحيل لم يُطبَّق.

## نقاط الـ API
| المسار | الطريقة | الصلاحية |
|---|---|---|
| `/api/register` `/api/login` `/api/logout` | POST | عام |
| `/api/me` | GET | عام (يرجع null بلا جلسة) |
| `/api/tracks` | GET | عام (بيانات وصفية فقط) |
| `/api/peek/:id/front\|back` | GET | عام — صورتا المعاينة |
| `/api/file/:id` | GET | **جلسة مسجّلة** — ملف PDF من R2 |
| `/api/my-logo` | GET/PUT/DELETE | صاحب الجلسة |
| `/api/my-logo-pos` | POST | صاحب الجلسة |
| `/api/settings` | GET عام / POST مدير | قفل الطباعة |
| `/api/admins` `/api/users` | GET/POST/DELETE | مدير |
| `/api/tracks/:id/file` | PUT | مدير — استبدال ملف مسار (يظهر للجميع فورًا) |

## الأمن — ما هو قائم وما هو ناقص
قائم: الجلسة كوكي HttpOnly/Secure/SameSite، الملف الكامل خلف الجلسة، الشعار لكل مستخدم على حدة، لا أسرار في المستودع.
ناقص ومقصود توثيقه:
- لا تحقق OTP: الجوال تعريف لا إثبات هوية. من يعرف رقمًا مسجَّلًا يدخل به.
- لا تحديد معدل على `/api/login` و`/api/register` — أضف Rate Limiting أو Turnstile قبل التدشين العام.
- مستخدم مسجّل يستطيع تحميل ملف PDF من `/api/file/:id`. المنع الفعلي يحتاج بث صفحات كصور، وهو تغيير أداء كبير.
- الطباعة تُنتج صورًا بدقة 2x؛ 122 صفحة تستهلك ذاكرة على الأجهزة الضعيفة.
